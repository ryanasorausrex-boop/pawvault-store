PAWVAULT — free starter website

Files:
- index.html: complete responsive storefront landing page (HTML/CSS only).

To publish for free:
1. Create a GitHub account with help from a parent/guardian if needed.
2. Create a new public repository named pawvault-site.
3. Upload index.html to the repository root.
4. In Settings → Pages, choose Deploy from a branch, select main and /(root), then Save.
5. GitHub Pages will provide the public website URL.

Before accepting orders:
- Replace illustrative product visuals with real supplier/product photos.
- Confirm materials, price, customisation options, delivery and returns with the supplier.
- Add a real order/contact method and privacy/returns information.
- Have a parent/guardian handle seller accounts, payment setup and fulfilment.
